# Skills

[English](README.md) | 中文

我原创和经常使用的 Agent Skills

## 安装

```shell
npx skills add micooz/skills
```

## 列表

- [batch-plan-execute](./skills/batch-plan-execute/): 让 Coding Agent 批量编写计划和执行计划的 Agent Skill，支持自由评审、持久化、checklist。
- [deslop](./skills/deslop/): 精简注释与文档冗余的 Agent Skill：清除复述代码的注释、历史或过时说明、被注释掉的代码、过度解释，以及已完成却仍写成现行指南的计划。只改注释和文字，不改可执行代码。
- [product-naming](./skills/product-naming/): 为产品、项目或工具提供命名方案、解释命名隐喻，并调研 `.com`、`.design`、`.art` 等域名可用性和价格信号的 Agent Skill。
- [publish-piano-sheet](./skills/publish-piano-sheet/): 将原始音频转换为钢琴谱，生成 PDF/MIDI/MusicXML 交付物，生成特效钢琴演奏视频并发布至 YouTube，最后在 mymusic5 上架销售乐谱的 Agent Skill。
